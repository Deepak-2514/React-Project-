# Resources

## Free books and guides
- **The Linux Command Line**, William Shotts: https://linuxcommand.org/tlcl.php (best beginner book, free PDF)
- **Bash Guide** (Greg's Wiki): https://mywiki.wooledge.org/BashGuide
- **Bash Pitfalls**: https://mywiki.wooledge.org/BashPitfalls
- **Arch Wiki**: https://wiki.archlinux.org (the best Linux docs, useful on any distro)
- **Linux Journey**: https://linuxjourney.com
- **The Art of Command Line**: https://github.com/jlevy/the-art-of-command-line
- **Missing Semester (MIT)**: https://missing.csail.mit.edu (shell, vim, git, debugging)

## Paid books (worth it)
- *How Linux Works*, Brian Ward: internals explained clearly (month 3+)
- *UNIX and Linux System Administration Handbook*, Nemeth et al.: the sysadmin bible
- *Linux Pocket Guide*, Daniel Barrett: quick reference

## Practice and games
- **OverTheWire Bandit**: https://overthewire.org/wargames/bandit/ (do it alongside weeks 1–10)
- **Linux Survival**: https://linuxsurvival.com
- **SadServers**: https://sadservers.com (real broken-server troubleshooting scenarios. Great for month 3)
- **TryHackMe Linux Fundamentals**: https://tryhackme.com
- **Vim Adventures**: https://vim-adventures.com
- **Exercism Bash track**: https://exercism.org/tracks/bash
- **cmdchallenge**: https://cmdchallenge.com

## Tools to bookmark
- **explainshell**: https://explainshell.com (paste a command and it explains each part)
- **crontab.guru**: https://crontab.guru
- **ShellCheck**: https://www.shellcheck.net
- **regex101**: https://regex101.com
- **tldr pages**: https://tldr.sh

## Video
- **freeCodeCamp: Linux for Beginners** (YouTube, full course)
- **NetworkChuck: Linux for Hackers** series
- **Learn Linux TV** (YouTube): sysadmin-focused
- **DistroTube** (YouTube): desktop, tools, Vim

## Certifications (after the 3 months)
- **LFCS** (Linux Foundation Certified Sysadmin): practical, performance-based
- **RHCSA** (Red Hat): practical, highly respected
- **CompTIA Linux+**: multiple choice, broad
